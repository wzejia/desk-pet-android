## 2. 判定（守门线=不回退）

- **TOTAL PSS：不回退 ✓**（两态均改善，空闲 −2.1 / KWS −5.9，抖动带左移；抖动序列
  215/216/216/…全程稳态无爬坡 → 无泄漏形态）。
- **Native Heap：+1.7~2.0MB 稳态台阶 ⚠**——超出 NH 分辨力，且 TOTAL 同步改善（净占用仍降）。
  形态=紧带宽台阶（88.0~88.2，10 样本零漂移），**非泄漏**；定性假设：Phase 3 新增缓存的
  结构性成本（MarkdownContent 列宽缓存 / ESP 加密库池化 / PetLogger 缓冲），**未归因**。
  → 处置：10-24 复评或现场批时做一次 heap dump 差分归因；若归因确认为缓存收益的对价且
  TOTAL 净降，建议由领导裁定带内豁免。
- **首帧：中位 +20ms ⚠ 待定性**——n=10 样本带（269~382）与基线带（259~289，n=7）重叠过半，
  基线自身有 679 离群、本次有 484 离群，方差大。SEC-3 ESP 初始化在 added 之前（首帧段
  added→drawn 不含它），非首嫌疑；晚间板况/样本量均为干扰源。→ 处置：现场批或 10-24 追加
  n 至 ≥15 复测；若中位持续 ≥300ms 再立项查因。

**总判定：核心守门线（内存 TOTAL）不回退且改善；两项 ⚠ 均为待定性观察项，不构成回退定案。**
