# v21 - S17 全屏字幕三合一适配（2026-08-29 模拟器+板子验收）

## 方案（用户拍板：跨区字幕 + 比例系统化 + 列宽钳制）

原型：`designs/xiaoduo-motion-preview/字幕适配方案对比.html`「★ 推荐」变体。

1. **比例系统化**：宠物宽 = min(0.62×屏宽, 440dp, 0.45×屏高等比)--横屏/矮屏按高约束收敛，
   拔除 S14 遗留「横屏宠物顶格压字幕」根因；状态区底距 = max(120dp, 19%屏高)。
2. **跨区字幕**：字幕区 = 宠物底+16dp -> 状态区顶-12dp，底对齐可滚动，
   高度 clamp(跨区实际值, 64dp, 28%屏高)。
3. **列宽钳制**：字幕/状态列宽 = min(屏宽-48dp, 520dp) 居中；字号随 min(宽,高)/360 缩放
   钳 [1.0, 1.3]。
4. **上让位规则**（横屏防护栏）：宠物 42% 中心若侵入 64dp 字幕兜底区则上移；
   顶到 0 仍放不下则等比缩宠物（极端横条屏，布局不破优先于宠物大小）。

**关键性质**：360×792 手机上所有锚点与 S14-2 验收值一致（零回归，单测黄金值锁定）。

## 实现

- 布局数学抽纯 Kotlin `ui/FullscreenVoiceLayout.kt`（输入宽高 dp、输出 9 项锚点），
  Android 层（FullscreenVoiceScreen）只消费计算器输出，旧布局常量（440dp/0.62/112/150）
  全部删除归一到计算器。
- 字幕/状态区共享列宽锚点（居中 520dp 钳制）；caption 与字幕 lineHeight 乘 fontScale。
