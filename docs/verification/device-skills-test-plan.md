## 2. 话术域（匹配器实际接受的输入，含容错变体）

- 设备名词（**必须出现其一**）：整理台/整理臺/实验台/試驗台/實驗台 ｜ 净化柜/淨化柜/净化櫃/淨化櫃
- 开机词：开机/打开/开启/启动/开一下/开开/开始；关机词：关机/关闭/关掉/关上/停下/停机/停止
- 模式词：整理台=自动/感应（缺省手动）；净化柜=强力/快速（缺省标准）
- 净化短语档位：「强力/快速/标准+净化」本身含开机语义（仅净化柜）
- 风速词：一档/1档/二档/2档/三档/3档、低速/中速/高速/低档/中档/高档、「风速调到2」（数字）
- 查询词：状态/温度/湿度/pm2/PM2/空气/怎么样/开了吗/开着吗/运行
- 口语前缀任意（帮我把/请/给我…匹配是 contains 语义）

## T1 语音控制·整理台（KWS 唤醒 → 说话 → TTS 播报结果）

前置：P1-P6 全过；每条先「小朵小朵」唤醒，听到「在听」后再说话术。
连续设备命令**间隔 ≥3 秒**（设备侧约束，违反可能丢命令——设备文档实测约束）。

| # | 说的话术 | 预期命令 | 预期播报（TTS） | 设备动作 |
|---|---|---|---|---|
| T1-1 | 打开整理台 | PowerOn(ZLT,0) | 整理台已打开+温湿度 | 开机·手动模式 |
| T1-2 | 整理台切自动模式（说「整理台打开自动」） | PowerOn(ZLT,1) | 整理台已打开+温湿度 | 切自动 |
| T1-3 | 启动整理台感应模式 | PowerOn(ZLT,2) | 整理台已打开+温湿度 | 切感应 |
| T1-4 | 整理台风速调到二档 | FanSpeed(2) | 风速已调到中速档 | 风速 2 |
| T1-5 | 把整理台风速调到高速 | FanSpeed(3) | 风速已调到高速档 | 风速 3 |
| T1-6 | 整理台风速一档 | FanSpeed(1) | 风速已调到低速档 | 风速 1 |
| T1-7 | 整理台什么状态 | QueryStatus | 整理台运行中/已停止+温湿度 | 无 |
| T1-8 | 关掉整理台 | PowerOff(ZLT) | 整理台已关闭 | 关机 |

通过标准：TTS 播报与预期一致 + **设备面板实际动作一致**（回读已验，目视复核）+
logcat 出现 `device skill hit:` 与 `always-on KWS` 轮次日志。

## T5 异常与边界

| # | 场景 | 操作 | 预期 |
|---|---|---|---|

## 5. 已知边界（不算 FAIL）

- 模拟器无法端到端（`input text` 仅 ASCII + 无设备局域网）——中文话术必须在板子现场验

- 「实验台」也算整理台名词（简繁/别名词表内），属预期容错
